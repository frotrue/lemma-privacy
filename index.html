Lemma 개인정보처리방침

시행일: 2026년 11월 11일 · 개발자: Frotrue

English version

Lemma(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다.

저장하는 정보

사용자가 작성한 노트와 앱 설정은 사용자의 기기 안, 앱 전용 저장소에만 저장됩니다. 개발자는 이 정보에 접근할 수 없고, 앱은 이 정보를 어디로도 전송하지 않습니다.

계정과 추적

앱에는 회원 가입이 없습니다. 분석 도구, 광고, 추적 기능을 쓰지 않습니다.

인터넷 사용

노트에 웹 주소의 이미지를 넣으면 그 이미지를 표시하기 위해 해당 웹 서버에 요청이 갑니다. 이때 그 서버는 일반적인 웹 접속과 같이 IP 주소 등을 볼 수 있습니다. 노트의 외부 링크를 누르면 기기의 브라우저에서 열립니다.

기기의 백업 기능

Android의 백업 기능이 켜져 있으면 기기 제조사나 Google의 백업에 앱 데이터가 포함될 수 있습니다. 이는 기기의 설정에 따르며 앱이 제어하지 않습니다.

데이터 삭제

앱을 삭제하면 앱에 저장된 노트와 설정이 기기에서 삭제됩니다.

Lemma Privacy Policy

Effective date: November 11, 2026 · Developer: Frotrue

Lemma ("the app") does not collect personal information.

What is stored

The notes you write and the app's settings are stored only on your device, in the app's private storage. The developer has no access to them, and the app does not send them anywhere.

Accounts and tracking

The app has no sign-up. It uses no analytics, advertising or tracking.

Internet use

If you put an image from a web address into a note, the app requests that image from its web server in order to show it. That server can see what any website sees on a visit, such as your IP address. External links in a note open in your device's browser.

Device backup

If Android's backup feature is turned on, the device maker's or Google's backup may include the app's data. This follows your device settings and is not controlled by the app.

Deleting data

Uninstalling the app deletes the notes and settings stored in it from your device.

Changes

Changes to this policy will be posted on this page.
